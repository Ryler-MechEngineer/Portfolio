# Replacement Gear in Onshape

**Role:** Independent project, 2026
**Tools:** Onshape, 3D printing
**Focus:** Reverse engineering a real part, parametric CAD, working in a second CAD platform

## Summary

A gear broke inside a household mop. I modeled a replacement in Onshape. I picked Onshape on purpose, because I have years of SOLIDWORKS experience and did not want to depend on one CAD program. The replacement works, but only after I changed the gear ratio to make it fit.

## Objective

Learn a new CAD platform by using it to fix a real, broken part.

## Design decisions

My first replacement, sized from the broken gear, was not big enough, so its teeth did not mesh with the mating gear. I tried lengthening the teeth, but that did not work because of the geometry. My goal was to keep the original gear ratio. In the end I had to increase the gear ratio so the geometry would mesh.

## Challenges

- Adjusting to a new CAD interface and workflow.
- Turning the geometry of the existing part into a replacement design.
- Working out which dimensions and gear features decide fit and function.

## What failed

The first attempt did not mesh, and lengthening the teeth did not fix it. Keeping the original ratio was not possible with the available geometry.

## Result

The replacement works fine, and I have not seen the new gear ratio affect how the mop performs.
