# Replacement Gear in Onshape

**Role:** Independent project
**Tools:** Onshape, 3D printing
**Focus:** Reverse engineering a real part, parametric CAD, working in a second CAD platform

## Summary

A gear broke inside a household mop. I modeled a replacement in Onshape. I picked Onshape on purpose, because I have years of SOLIDWORKS experience and did not want to depend on one CAD program.
